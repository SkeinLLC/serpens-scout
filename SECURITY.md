# Security policy

Serpens Scout is designed for passive research.

- Do not submit private, credential-bearing, or victim-specific URLs to public
  services.
- Do not point the tool at live malware infrastructure. The HTTP allowlist rejects
  arbitrary hosts.
- Do not place real credentials in fixtures or archives.
- Do not publish malware samples in this repository.
- Review generated STIX before importing it into a production TIP.

Report a vulnerability through GitHub's private security-reporting feature. Do not
open a public issue containing credentials, victim data, or live exploit material.
